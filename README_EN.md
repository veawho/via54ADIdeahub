## 🛠️ MCP Tools Exposed

1. `deconstruct_and_evolve_copy`: 4-D reverse-engineering of benchmark copy + 5 evolved alternatives.
2. `reason_creative_strategy`: Multi-archetype slogan matrix + manifesto + Critic scoring.
3. `polish_and_diagnose_copy`: Copy health score + preachiness audit + 3-D rewrites.
4. `explore_creative_puns`: Conceptual double entendre + cringe risk evaluation.
5. `audit_advertising_compliance`: Advertising law absolute superlatives & taboo linter.
6. `search_audience_language`: Subculture dialect, tone guidelines, and taboos.
7. `search_knowledge_base`: Hybrid RAG search across award-winning campaigns.
8. `list_advertising_cases`: Case filtering by industry, brand, award tier.

# 《疯传：让你的产品、思想、行为像病毒一样入侵 (Contagious: Why Things Catch On)》— 文案写作与广告策略核心心法

> **作者**: 乔纳·伯杰 (Jonah Berger - 沃顿商学院市场营销学教授) | **学派归属**: 病毒式传播与社交动力学派
> **核心理论**: 事物的疯传不是偶然的运气，而是背后严格符合 6 大 STEPPS 病毒法则。人们传播某件事物，本质上是为了装扮自己的社交镜像。文案是用户借来展现自己品味、智慧与立场的社交道具。
> **思考方式**: 社交货币与高唤醒生理情绪。人们为什么分享？为了让自己显得高尚、机智、有趣，或者因为被文字唤醒了愤怒、敬畏、狂喜等高能量生理情绪。

## 🏛️ 战略策略框架
```json
{
  "stepps_model": [
    "S - Social Currency (社交货币): 让人转发时显得有品味、有见识、懂得内幕",
    "T - Triggers (诱因): 将产品强行绑定到日常高频线索（如咖啡绑定KitKat，周四绑定肯德基）",
    "E - Emotion (高唤醒情绪): 激发敬畏、狂喜、爆笑、义愤，避开忧伤、平淡与无聊",
    "P - Public (公共性): 把私密行为变成公开可视的社交仪式（如苹果发光logo、微信运动步数）",
    "P - Practical Value (实用价值): 提供立竿见影的避坑指南、省钱干货、自救攻略",
    "S - Stories (特洛伊木马故事): 把品牌硬核信息包裹在一个让人欲罢不能的好故事里"
  ]
}
```

## ✍️ 具体写作技法与修辞模型
- 高频日常场景借势：‘每当你在深夜改第8版PPT时’（诱因锚定）
- 身份徽章化：把文案写成受众的朋友圈宣言（‘今日精神离职，请勿打扰’）
- 制造反常识奇观：让人倒吸一口凉气的真实事实

## 🏆 传世经典金句案例与深度解构
- **【Blendtec 破壁机】**  
  *金句*: `Will It Blend? (它能被绞碎吗？)`  
  *深度拆解*: 把全新 iPhone 和高尔夫球丢进搅拌机打成粉末，极度敬畏的高能量情绪引爆全网数十亿次播放。  
- **【肯德基疯狂星期四】**  
  *金句*: `疯狂星期四，V我50！`  
  *深度拆解*: 完美结合周四高频诱因(Triggers) + 搞笑发疯高能量情绪(Emotion) + 全网二创社交货币(Social Currency)。

## ⚙️ 算法启发与工程指标
- **目标指标**: STEPPS 病毒疯传指数 (STEPPS Virality Score)
- **判定规则**: 社交货币、场景诱因、高能量情绪与故事包装度多维加权打分。
